## 🇬🇧 English

An open-source HTML5-based game engine and sprite editor. You can download the source code, run it directly in your browser, and start editing or adding new features!

### 📥 1. Download the Source Code
You can get the source code in two ways:
* **Option A (ZIP Download):** Click on the green **Code** button at the top of this repository, then select **Download ZIP**. Extract the files on your device.
* **Option B (Git Clone):** Run the following command in your terminal:
  ```bash
  git clone [https://github.com/abidin-tech/blarta-make.git](https://github.com/abidin-tech/blarta-make.git)
   This is very simple and took me half an hour, and you can develop it further.  You can do it for Android and Windows.
