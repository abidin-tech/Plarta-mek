## 🇬🇧 English

An open-source HTML5-based game engine, sprite editor, and emulator for custom `.mkp` games. Built with pure JavaScript, Canvas, and JSZip.

### 📜 Features
- **Built-in Sprite Editor:** Create 8x8 pixel art directly in your browser.
- **Custom Game Format (`.mkp`):** Package scripts, metadata, and assets into a lightweight format.
- **Touch-Friendly Controls:** Works seamlessly on mobile devices and desktop.
- **Standalone Runtime:** Play and test games in real time.

### 🚀 Getting Started
1. Open the studio live at: `https://your-username.github.io/your-repo-name/`
2. Draw your sprite or write your JavaScript code.
3. Click **Export .mkp** to download your game file.
4. Click **Run** to test it inside the canvas emulator.

### 🤝 How to Contribute & Submit Games
We welcome all contributions!
1. Fork this repository.
2. Add your custom `.mkp` game inside the `/games` directory or submit code improvements.
3. Open a **Pull Request**.

## 🇸🇦 العربية

محرك وصانع ألعاب مفتوح المصدر يعمل على الويب والهواتف، يتيح لك رسم الشخصيات، كتابة الأكواد، وتصدير/تشغيل الألعاب المخصصة بصيغة `.mkp`.

### 📜 المميزات
- **محرر سبرايت مدمج:** رسم شخصيات بكسل بدقة $8 \times 8$ مباشرة داخل المتصفح.
- **صيغة ألعاب مخصصة (`.mkp`):** ضغط السكربتات والرسومات والبيانات داخل حزمة خفيفة.
- **دعم تحكم اللمس:** مصمم ليعمل بسلاسة على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر.
- **محاكي وتشغيل فورِي:** اختبار وتجربة الألعاب مباشرة على الـ Canvas.

### 🚀 طريقة الاستخدام
1. جرب صانع الألعاب مباشـرة عبر الرابط: `https://your-username.github.io/your-repo-name/`
2. ارسم شخصيتك في تبويب السبرايت أو اكتب كود اللعبة بلغة JavaScript.
3. اضغط على **تصدير .mkp** لتحميل ملف اللعبة على جهازك.
4. اضغط على **▶ تشغيل** لتجربة اللعبة داخل المحاكي.

### 🤝 كيف تساهم وتضيف ألعابك؟
